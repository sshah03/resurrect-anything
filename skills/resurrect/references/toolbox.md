# Toolbox

Every script lives in `${CLAUDE_SKILL_DIR}/scripts` and has `--help` (in these references `$S/` stands
for that folder: write the full path in each call). Treat them as black boxes unless
one fails. Run them from the project root; relative paths mean paths inside the active workspace.

| Script | Commands |
|---|---|
| `ledger.py` | `status` (start here; also names optional tools that are missing and the commands they disable), `init`, `use`, `add`, `add-batch` (evidence + leads from one JSONL file; `key`s carry across files, so a retry can cite `@k1`), `edit ID|@key` (correct a merged item's quote, claim or locator in place, showing old -> new; `--dry-run`; `--forget` drops the old text), `link` (evidence to questions), `supersede` (retire an item a later find overtook), `pack` (writes pack/FACTS.md and checks the build pack stands alone: files the README names in backticks exist (mark a lost one `name` (lost), or list it under an Unknown/Lost heading), reference images are not blank, no contact details), `lead add/list/done`, `question add/list/set`, `round start/end` (yield and saturation), `versions` (`propose`, `add`, `target`, list), `find`, `packet` (everything about one feature, with the frames to open, for build time), `mourn` (soul ranking), `check-spec`, `approve`, `phase`, `stop` (record a law-4 stop), `viewport WxH` (the device or stage size, settable after init), `validate` (schema and reference checks) |
| `wayback.py` | `alive` (is it alive right now: DNS, status, redirects, tombstone words; says when the domain now hosts a different site), `inventory DOMAIN --to <death>` (every archived file under the domain and its subdomains, by kind; program files flagged; files "known, never captured" listed first; numbered series summarised (`clip_N.swf` x318, gaps), and one file served under every name flagged; `--save FILE` keeps every row it counted; hosts and folders a program's FlashVars name that the archive holds nothing under are listed as leads; a later owner's site or a parking page is detected and left out, `--all-eras` keeps it), `known SITE` (every page a small site is known to have had: captured, error, or only linked; GeoCities mirrors checked), `changes URL` (a page's archived history: version strings, What's New, lines that came and went), `timeline` (lifespan, design eras, death signals; `page_change` reads the versions to find when the page stopped embedding its program or turned into a placeholder or a parking page, which page sizes cannot show), `mirror URL TS` (restore pages plus every asset they use, links rewritten, MANIFEST of original vs missing; `--original` for program files; `--from-inventory FILE --match RX` downloads inventory rows directly, `--parallel 3`; a download that is still receiving data is never cut off: only stalls of 60 s time out and are retried, `--max-seconds 300` stops new requests, and whatever is left is listed with a resume command), `urls --group` (site map), `find DOMAIN[/path] WORD` (archived URLs containing a word; a path, e.g. `home.att.net/~user`, searches just that folder), `links URL TS [TS...]` (the links on several captures of index or list pages merged into one dated list: rebuilding a lost index), `text` (readable text of an archived page's article body; follows frames; `--whole` for everything), `fetch` (raw capture; without a ts, program and media files come from their earliest capture; `--original` for program files, saved as data, never run), `cdx`, `available`, `api` (archived JSON/XML) |
| `community.py` | `discuss` (HN, Reddit, comments on the videos that name it, all dated, most descriptive first, plus a forum/newsgroup/blog/review search plan, a retro one for targets before 1995; `--maker` for the studio or channel so namesakes drop out, `--videos ID,ID` to pick the videos), `yt-comments`, `hn`, `reddit`, `yt` (transcripts; `--timed` keeps caption timings, into dossier/media/captions by default; `--meta-only` lists videos with durations and chapters), `frames` (stills, or `--fps` bursts to measure motion), `wiki` (an article as it read on a date; `--expand` renders tables), `media` (files on a fan wiki; `--download`), `rips` (soundtrack/sprite/sound rips: KHInsider and archive.org, plus the searches for The VG Resource sites), `github` (disassemblies, ports, clones, official releases; `--makers` searches the makers' own and archive organisations), `store` (still sold? `--seller`), `graveyard` (Killed by Google), `audio` (measure sounds: onsets, gaps, transient length, dominant frequency) |
| `footage.py` | `get` (one local copy of a video), `audio-check` (triage recordings by audio first), `scenes` (every distinct screen with timestamps, one folder per video: the screen inventory; `--region` for a game window inside a bigger recording), `sprite` (moving things cut out and merged per pose; `--follow x,y`, `--native-width`, `--vector`), `cut` (static or smooth art cleared from its background; `--plate`, `--key`; `--fill-holes N` and `--largest` when the art shares colours with the plate), `merge` (clean plates and filled-in pictures from frames that each hide a part; `--how sharpest` for smooth art; `--scroll auto` builds a side-scroller's background panorama and its repeating tile), `stage` (frames from different videos brought to the original stage size), `tiles` (puzzle boards: one sprite per tile type), `hud` (a score/timer/counter region over time; warns when the box catches motion rather than values; `--measure bar|marker` reads a timer bar's length or a marker's position per frame, with its drain rate and refills), `sfx` (sound effects cut and grouped; `--sheet`, `--events`; runs on the drums stem when `stems` has split that video; `--minus-loop` subtracts the music loop first), `lines` (voice lines cut by caption timing), `common-audio` (does audio recur across uploads? matched window by window, so two edited recordings of the same play line up), `stems` (music, effects and voice split apart with Demucs; optional install), `loop` (one clean loop of the music; `--stack` medians every cycle in the window, restarts included, so narration and effects drop out), `gif` (frames with their delays), `count` (how many objects are on screen per frame), `merge --layers auto` (one panorama per parallax layer) |
| `footdiff.py` | measure the rebuild against the original's footage: `record` (drive it with timed inputs and record a video), `compare` (align in time and speed; visual match, event timing, motion; side-by-side video), `screens` (every original screen beside the rebuild's closest screen) |
| `enhance.py` | small or blurry art made usable without stretching: `native` (pixel art: the original pixel grid and palette from a scaled, compressed picture), `stack` (several takes solved into a finer picture), `upscale` (smooth art via Real-ESRGAN, with a review sheet of what the model changed; pixel art is routed to `native`), `vector` (flat art to SVG), `setup` (installs the Python extras: Pillow, numpy, Playwright with Chromium, yt-dlp, vtracer, in an environment the other scripts switch to by themselves, made with uv or a Python 3.12+ found on PATH; checks that Chromium starts; then Real-ESRGAN, skipped with the reason if its download fails; `--audio` adds Demucs) |
| `fit.py` | the rules behind readings: `rule` (formula search with round-number snapping, the breaking reading per failed rule, the reading that would settle a tie), `motion` (gravity, taps set or add, terminal speed, per-frame constants), `table` (lookups and disagreements), `cutoffs` (rank and grade boundaries), `timing` (spawn intervals and type cycles); `--batch` writes the inferred ledger line |
| `blueprint.py` | a screen's reference frame as build input: `rectify` (a photographed screen warped flat), `make` (measured blocks with CSS boxes, colours, crops and a scaffold.html), `diff` (the rebuild against the reference each round: layout edges that are off, blocks that moved, changed colour or are missing, with a diff and onion image) |
| `inspect_js.py` | an archived web-app client (minified JS/CSS): UI strings, message tables, CSS, palette; `--diff` across capture dates |
| `inspect_swf.py` | an archived Flash file: stage, fps, text, palette, sounds, scripts and numbers; `--extract DIR` saves sounds, bitmaps, embedded video (as .flv, and .mp4 with ffmpeg), embedded files and streamed audio (nested SWFs included) |
| `inspect_app.py` | an archived application's own assets and words, parsed and never run: `pe` (Windows .exe/.dll, 16/32/64-bit: icons and cursors as .ico/.cur + PNG, bitmaps, menus with shortcuts and status-bar prompts, dialogs in dialog units, strings, accelerators, toolbars, version), `chm` (HTML Help: every page, contents tree, index, topic texts), `hlp` (WinHelp: titles, keywords, topic text), `mac` (.app folder, zip or dmg: Info.plist, .strings per language, icns as PNG, nib labels, images, sounds, Help Books, Mach-O archs), `a2` (Apple II disk images .dsk/.do/.po/.2mg, DOS 3.3 and ProDOS: catalog, every file, Applesoft and Integer BASIC listings, text files, hi-res screens as PNG), `list` (what is inside a zip, tar or ISO, programs first; `--get` copies them out) |
| `archive_search.py` | archive.org items (manuals, magazines, press kits, videos, software): `fulltext` (search the scanned text of every book and magazine; snippets are short, `--chars N` shows whole paragraphs of open items, `--walk N` reads on through lending-only ones and says how far it got), `grep ITEM PHRASE` (pages inside one item; a phrase by default, `--any` for the words anywhere; the leaf is the one `pages` takes), `search`, `files`, `download` (`--original` for program files and disk images), `pages` (page images of scanned books), `inside` (documents inside a disc image or zip) |
| `pantry.py` | recipes: `hunt` (where an old product's label survives: pack photos, collectors credited in articles, every spelling of the name), `label` (Open Food Facts; `--barcode` lists every uploaded photo), `retail URL` (label data from a retailer page), `food` (USDA per-100 g; `--offline`), `solve` (fit grams to the label), `match` (label match; batch amounts with spoon measures) |
| `extract.py` | `page` (skeleton, nav, forms, design tokens, privacy scan), `css`, `templates DIR`, `pdf` |
| `shots.py` | `capture URL out.png` (`--selector`, `--clip`, `--mask`), `wayback URL TS out.png` (a blank or failed replay is saved as `*.FAILED.png` and exits 3; flags dead embeds and images served from other years), `play URL --steps` (drive an emulated original), `swf FILE|DIR --steps` (an archived Flash movie run in a pinned, self-hosted Ruffle, muted, with its sibling files: screenshots of every state, files it asked for that are missing; `--grid 50` saves a copy of each shot with labelled stage coordinates for clicks), `fetch-image`, `sheet` (contact sheet: one cell size, each label with the image's real size), `probe` (colours, rows, where a colour sits), `track` (an object's position per frame; gravity fit), `crop`, `redact`, `compare` |
| `verify.py` | `lint`, `run --serve app` (journeys; the viewport comes from `ledger.py init --viewport` or `ledger.py viewport WxH`), `manual` (user-recorded checks), `visual` (every screen in codex/screens.json against its reference, with a look sheet per pair), `shape` (APIs vs archived responses), `feature F3 --status built` (mark a feature built), `score` (codex/SCOREBOARD.md) |
| `unveil.py` | `museum/index.html` from `museum/exhibit.json` (recipes show the recipe card) |
| `serve.py` | a test server with Range requests (used by `verify.py --serve`) |

## Which tool answers which question

| You need | Reach for |
|---|---|
| Is it really gone? | `wayback.py alive`, `community.py store/graveyard`, a search for relaunches and official releases |
| What survives in the archive? | `wayback.py inventory` for each domain (product, developer, publisher), then `timeline` |
| A personal or fan site the archive caught only partly | `wayback.py known <site>`, then `mirror` the captured pages; mirrors, copies and quotes for the rest (rebuild-guide) |
| Which versions existed, and when? | `wayback.py changes` on store listings, changelogs and help pages; dated reviews; `ledger.py versions propose` |
| What people remember and how it worked | `community.py discuss`, then a discourse reader (subagent-briefs.md) |
| The original's own files | `inventory` program files, `fetch --original`, `archive_search.py`, `community.py github --makers`, `rips` |
| Its screens, art and motion | videos: `footage.py scenes`, `sprite`, `cut`, `merge`, `hud`; screenshots: `shots.py probe`; bursts: `shots.py track` |
| Its sounds and music | rips first; then `footage.py audio-check`, `stems` (when music or a narrator covers the effects), `sfx --sheet`, `lines`, `loop`, `common-audio` |
| Its art is small, blurry or compressed | `enhance.py native` (pixel art), `stack` (many takes), `upscale` (smooth art, then read the review sheet), never a plain stretch |
| Its words and colours (web apps) | `inspect_js.py` on archived bundles; `extract.py page` on archived HTML |
| The rule behind scores, speeds, timers, ranks or spawns | a readings table (from `hud`, `track`, guides), then `fit.py rule/motion/table/cutoffs/timing` |
| Build a screen exactly | `blueprint.py rectify` (photos of a device), `make`, then `diff` each round |
| Did the build use the research? | `ledger.py packet <feature>` while building; `verify.py score` rows Screens compared and Evidence used (`codex/UNUSED-EVIDENCE.md`) |
| A recipe | `pantry.py hunt` (pack photos and collectors, for anything pre-2010), `label`/`retail`, the brand site in Wayback, then `food`, `solve`, `match` |
